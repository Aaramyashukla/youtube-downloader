# ⚒ youtube-downloader
A simple python project to download youtube video using yt-dlp.
⚒ - PROJECT DISCRIPTION-----
THis project allow users to download a youtube video
entering its url....
⚒ Technologies Used.....
- Python
- yt - dlp
- os module

  ✨ Features
  - Enter a youtube video URL
  - Download video with audio
  - Save videos in MP4 format
  - Automatically create a download folder
  - download only one video at a time
